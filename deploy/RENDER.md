# Everything on Render (one place)

Two Render services, both free, created from `render.yaml` in the repo root:

| Service | What it is |
|---|---|
| `jansevak-api` | Backend: Core API + AI Lite behind one gateway. Rebuilds the demo data (and photos from `demo_assets/`) on every start. |
| `jansevak-web` | The React app as a static site. This is the link you share. |

The AI works in two modes, switched automatically:
- **Real AI** (Ollama on your friend's GPU laptop) whenever the laptop is on and connected.
- **AI Lite** (template replies, no GPU, runs on Render) whenever the laptop is off, asleep or the tunnel is down.

The backend tries the laptop first and falls back to AI Lite on its own, so the app never breaks if the laptop is off.

## Steps
1. Commit and push these files (`render.yaml`, `deploy/`) to GitHub.
2. render.com -> **New** -> **Blueprint** -> pick the JanSevak repo -> Apply. Two services are created and start building.
3. When `jansevak-api` shows **Live**, open it and copy its address, like `https://jansevak-api-xxxx.onrender.com`.
   Check `<address>/api/health` shows `{"status":"ok",...}`.
4. Open `jansevak-web` -> **Environment**. Set both to the address from step 3 (no slash at the end):
   - `VITE_API_URL`
   - `VITE_AI_API_URL`
   Save. Then **Manual Deploy -> Deploy latest commit** (these values are baked in at build time).
5. Open the `jansevak-web` address on your phone. Log in with `ayush@example.com` / `demo123`.

## Switching on the real AI (laptop)
One-time setup on the laptop is steps 1-2 and the tunnel tool in `DEPLOY.md` (AI service environment, Ollama models,
ngrok or cloudflared). Then, whenever you want the real AI live:
1. On the laptop (Ollama running): `powershell -ExecutionPolicy Bypass -File deploy\start_ai_laptop.ps1`
   (ngrok with a fixed address: add `-Tunnel ngrok -Domain your-name.ngrok-free.app`).
2. It prints an address. On Render -> `jansevak-api` -> Environment, set `REAL_AI_URL` to it and save. The backend
   restarts (about a minute, demo data reloads). **The frontend does not need a redeploy.**
3. Keep the laptop window open. If the address changes (cloudflared restarts), update `REAL_AI_URL` again.
4. To go back to AI Lite only: delete `REAL_AI_URL`.
Test: the Civic Assistant answers much more freely than the template replies.

## Things to know
- **Sleep:** a free service sleeps after ~15 minutes without visits and takes about a minute to wake. The wake-up also
  rebuilds the demo data, so anything created during the demo is reset. Open the link once a minute before showing it.
- **Instance hours:** the free plan has a monthly limit of running hours. The backend is deliberately ONE service
  (not two) to stay inside it. Check the current limits on render.com/pricing. Do not ping the service all day.
- **Versions:** `render.yaml` pins Python 3.12.7 and Node 22.12.0. If Render rejects either, pick a version it lists.
- **Photos and data:** change pictures in `backend/core_api/demo_assets/photos/`, push, and Render rebuilds them on the
  next deploy/restart.
- **Secrets:** `SECRET_KEY` is generated by Render. Do not commit a `.env`.
